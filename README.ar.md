# localhost_bridge — الدليل العربي

> هذا هو الدليل العربي المستقل للحزمة. المرجع الإنجليزي الكامل في
> [README.md](README.md) — وهذا مرآة عربية له بنفس العقود والأرقام.

جسر HTTP محلي يفتح لصفحات الويب قناة موثوقة الأصل إلى برنامجك المحلي: خادمك
يستمع على `127.0.0.1` حصراً (لا تعرّض للشبكة أبداً)، وصفحة الويب التي
يزورها المستخدم ترسل الأوامر إليه مباشرة من المتصفح. الجسر يفصل
**من يملك الكلام** و**كم يملك** — أما معنى الأوامر فيبقى كله في معالجك.

- **صفر تبعيات تشغيلية** — `dart:io` الصرفة، حزمة واحدة، بلا كود أصلي.
- كل رفض يحمل رمز خطأ ثابتاً (`error`) — هذا عقدك البرمجي.

## ما تحصل عليه

- استماع على `127.0.0.1` فقط، بمنفذ تختاره وبدائل تلقائية عند الانشغال.
- سياسة أصول واحدة تحكم الباب: **قائمة صريحة** (الافتراضي مغلق)، أو
  **الكل-المحصَّن** (كل أصل HTTPS صالح عبر تحصينات إلزامية)، أو
  **موافقة أول ظهور** (سؤال واحد لكل أصل جديد)، وكلها فوقها **طبقة
  توكن** مستقلة للتكاملات غير المتصفحة.
- تحصينات المتصفح: أصل HTTPS صالح، و`Sec-Fetch-Mode: cors`،
  و`Sec-Fetch-Dest: empty` — توقف النماذج المخفية و`no-cors`/beacon.
- حدود موارد صارمة في كل الأوضاع: سقف جسم بالبايتات، مهلة طلب، سقف
  مقاعد متزامنة، سقف عناصر JSON قبل الفك، وحصة لكل أصل في الدقيقة.
- صدى CORS للأصول المسموحة وحدها (أصل الطالب + `Vary: Origin`) — غير
  المسموح يُرفض قبل المعالج فلا يصل كودك والرد غير قابل للقراءة.
- معرف ارتباط لكل طلب (`X-Correlation-Id`) يُردّ إليك إن كان صالحاً.
- واجهة قياس وسجل (`BridgeTelemetry`) يكيّفها المضيف فوق سجله الخاص.

## البدء السريع

```dart
import 'dart:io';
import 'dart:math';
import 'package:localhost_bridge/localhost_bridge.dart';

void main() async {
  final server = LocalIntakeServer(
    // إلزامي: معالج أوامرك — الجسر لا يفهم الحمولات.
    onCommand: (cmd) async {
      print('from ${cmd.source}: ${cmd.payloads}');
      return const CommandOutcome(ok: true);
    },
    // إلزامي: منفذ القياس (ابدأ بـ const SilentTelemetry()).
    telemetry: const SilentTelemetry(),
    // إلزامي: مولد معرفات الارتباط — أي سلسلة فريدة لكل طلب. مولد
    // UUID بأسلوب Random.secure كامل في example/main.dart.
    correlationIdGenerator: () =>
        '${DateTime.now().microsecondsSinceEpoch.toRadixString(16)}'
        '-${Random.secure().nextInt(1 << 32).toRadixString(36)}',
    protection: IntakeProtection()
      ..update(
        policy: const OriginPolicy(
          allowed: ['https://portal.example.com', '*.partner.io'],
        ),
        // طبقة التوكن الاختيارية للتكاملات غير المتصفحة حصراً — يجب
        // حفظ التوكن وتسليمه للعميل خارج النطاق (البداية السريعة تتركها)
      ),
  );

  final port = await server.start(preferredPort: 9100);
  print('listening on http://127.0.0.1:$port');
}
```

ومن جهة الصفحة: `fetch('http://127.0.0.1:9100/', { method: 'POST', ... })`
عادي — الخادم يرد بترويسات CORS للأصول التي أذنت بها فحص، وكل أصل آخر
يُرفض **قبل تشغيل معالجك**: الطلب لا يصل كودك أصلاً والرد غير قابل
للقراءة. ومن صفحة HTTPS أضف `targetAddressSpace: 'loopback'` لخيارات
الطلب — دليل Chrome لإذن الشبكة المحلية يطلبه كي يبقى الطلب معفى من
حظر المحتوى المختلط ويُفحص حيز العناوين ضد الحلقة الراجعة بعد تحليل DNS.

## نموذج الأمن — اقرأه قبل اختيار السياسة

الجسر لا يستطيع معرفة هل الموقع شرعي أم مخترق: كل ما يراه ترويسة
`Origin` (يفرضها المتصفح ويزوّرها أي برنامج محلي) وترويسات `Sec-Fetch-*`
والحمولة.

- **مغلق افتراضياً**: السياسة الفارغة ترفض كل شيء — آمن للشحن كما هو.
- **القائمة** توقف المواقع المجهولة، ولا توقف موقعاً مدرجاً مخترقاً.
- **الكل-المحصَّن** يقبل أي أصل HTTPS صالح عبر التحصينات (أصل، طريقة
  إرسال، حصة لكل أصل) ولا يوقف موقع HTTPS خبيثاً يستعمل `fetch` —
  اسمه صريح الفاضح عمداً، وتحذير يسجَّل عند تفعيله.
- **موافقة أول ظهور** (`onUnknownOrigin`) تسأل برنامجك مرة واحدة لكل
  أصل جديد — الطبقة الوحيدة التي تجعل «إنسان كفل هذا الموقع» حقيقة.
  المرفوض يُتذكَّر للجلسة (تطبيق سياسة مغايرة يسحب المنح المحفوظة لا
  الرفض)، ومنحة «المرة» لا تُتذكَّر.
- **طبقة التوكن** مسار دخول مستقل لا حاجز فوق الأنماط الأخرى: التقديم
  بالتوكن الصحيح يعبر بلا ترويسات متصفح. وهي النمط الوحيد الذي يقاوم
  البرامج المحلية الأخرى — وهذا يصح ما دام لا مسار أصل يقبل: مع قائمة
  غير فارغة أو «الكل-المحصَّن» أو موافقة محفوظة، يستطيع برنامج محلي
  تقديم `Origin` مدرج (الترويسة يفرضها المتصفح وتُزوَّر محلياً) فيعبر
  بلا السر.
- **الحمولات غير موثوقة في كل الأوضاع**: معالجك يعقّمها (للطابعات:
  قائمة أوامر مسموحة، ومنع أوامر الإعداد والتخزين والبرمجيات) — والجسر
  يسقّف عدد عناصر JSON قبل الفك: عدّ خطي واحد للعناصر البنيوية
  (`{` و`[` و`,` خارج النصوص) ورفض بما فوق `maxJsonElements`
  (الافتراضي 10,000) برمز `payload_too_complex`، فلا يتضخم جسم صغير إلى
  مئات الميغابايت من الكائنات المفكوكة.

## مرجع سياسة الأصول

| حقل `OriginPolicy` | الأثر |
|---|---|
| `allowed` | أصول كاملة (`https://host`) أو مضيفات مجردة أو `*.example.com` للنطاقات الفرعية حصراً (الجذر يُدرج صريحاً). |
| `allowAllHardened` | كل أصل HTTPS صالح عبر التحصينات، مع تحذير صريح عند التفعيل. |
| `allowLocalHttp` | استثناء التطوير: قبول `http://localhost` و`http://127.0.0.1`. |
| `onUnknownOrigin` | سؤال الموافقة لكل أصل جديد (`allowAlways`/`allowOnce`/`reject`/`dismissed`) — لا يعطّل الطلب: يعود `origin_pending` فوراً مع `Retry-After` وتعيد الصفحة المحاولة؛ و`dismissed` يقفل السؤال بلا قرار: لا تُذكر ذاكرة ويُسأل الأصل مجدداً عند طلبه التالي. الأسئلة الجديدة بميزانية زمنية (10 في 10 دقائق): فوقها يعود `origin_pending` بلا سؤال جديد حتى يفرغ الكبار. |
| `reportOnly` | وضع الرصد للحصة وحدها: فوق الحصة يسجَّل كان-سيرفض ويُخدم؛ فحوص شكل الطلب ترفض دائماً — لا fetch شرعيا يفشلها قط. |
| `perOriginPerMinute` | حصة كل أصل في الدقيقة على مسار «الكل» (الافتراضي 30). |
| `listedPerOriginPerMinute` | حصة اختيارية لكل أصل على مسار القائمة أيضاً — صفر (الافتراضي) يُبقي المدرجين بلا حصة؛ والقيمة الموجبة تحصر طوفان أصل مدرج مخترق بالرمز نفسه `429 origin_rate_limited`. وضع المراقبة (`reportOnly`) يغطي هذه الحصة كحصة «الكل»، وإخفاق توكن يحمل أصلاً مدرجاً يُحسب على نافذته أيضاً. |
| `requireFetchMetadata` | مفعّل افتراضياً. يرفض مسارا «الكل» والاكتشاف الطلبات الخالية من `Sec-Fetch-Mode: cors` و`Sec-Fetch-Dest: empty` (`cross_site_blocked`) — فيغلق الإرسال الصامت من متصفحات بلا Fetch Metadata. عملاء التوكن بلا ترويسات لا يمسهم؛ عطّله فقط إن كنت تخدم مثلهم عبر المسارات المتصفحية. |
| `askTimeout` | أقصى عمر لنافذة موافقة صامتة (الافتراضي 60 ثانية). |

## عقد السلك (ما تراه صفحتك)

JSON في كل مكان: `POST` مع `Origin`، والردود تحمل `X-Correlation-Id`.
رموز الأخطاء الثابتة:

| HTTP | رمز `error` | المعنى |
|---|---|---|
| 200 | — | نجاح المعالج (`{"ok":true}`). |
| 400 | `duplicate_header` | ترويسة أحادية أُرسلت مرتين. |
| 400 | `invalid_utf8` / `empty_payload` / `unsupported_payload_shape` | الجسم ليس UTF-8 / لا حمولة صالحة / كائن JSON بلا مفاتيح أوامر معروفة. الجسم الذي يفشل فك JSON كلياً **ليس** 400 — يسقط نصاً خاماً كأمر (عقد «غير JSON يبقى خاماً» المختبَر). |
| 405 | `method_not_allowed` | المقبول `POST` (و`OPTIONS` للفحص المسبق) حصراً. |
| 403 | `origin_not_listed` وأخواتها | رفض سياسة الأصول (غير مدرج/مرفوض/غير قابل للتأكيد/تحصين الكل/نافذة موافقة مفتوحة). |
| 403 | `cross_site_blocked` | تحصين طريقة الإرسال: `Sec-Fetch-Mode` ليس `cors`. |
| 403 | `blocked_by_protection` | رفض سلطات المضيف (دفاع إعادة ربط DNS). |
| 408 | `request_timeout` | الجسم لم يصل في وقته. |
| 413 | `payload_too_large` / `payload_too_complex` | الجسم تجاوز سقف البايتات (الافتراضي 1MiB) / جسم JSON تجاوز سقف العناصر (الافتراضي 10,000 عنصر بنيوي، يُعدّ قبل الفك). |
| 415 | `unsupported_media_type` | جسم POST يحمل `Content-Type` خارج `BridgeConfig.allowedContentTypes` (الافتراضي `application/json` و`text/plain` — يغطي عملاء JSON والبوابات النصية؛ والغياب يمر لتكاملات المقابس الخام). أنواع نماذج HTML المخفية (`application/x-www-form-urlencoded` و`multipart/form-data`) تُرفض. الفحص بعد قبول المدخل، فمن ترفضه سياسة الأصل يرى رفض الأصل لا 415. انتبه: `text/plain` نفسه ترميزُ نماذج HTML صالح فيمر من هذه البوابة — صدُّ النماذج المتصفحية الفعلي بتحصين طريقة الإرسال (`cross_site_blocked`)، و`OriginPolicy.requireFetchMetadata` يمدّه للطلبات بلا الترويسات. |
| 429 | `origin_rate_limited` / `token_locked` | نفاد حصة الأصل / محاولات توكن فاشلة كثيرة في الدقيقة من هذا الأصل (محاولات بلا أصل تشارك نافذة واحدة؛ التوكن الصحيح يُرد أيضاً ما دامت النافذة مقفلة). |
| 503 | `server_busy` / `protection_disposed` | المقاعد ممتلئة (المقاعد والمعالجات المتجاوزة مهلتها وما زالت تعمل ميزانية واحدة للعمل الحي) / كائن الحماية أُغلق — أنشئ جديداً. |
| 504 | `handler_timeout` | معالجك تجاوز مهلته — **الأمر قد يكون نفّذ فعلاً**: عامل 504 كـ«نتيجة مجهولة» وفكّك التكرار بمعرف الارتباط قبل الإعادة. |
| 500 | `internal` / رمزك / `command_failed` | فشل المعالج؛ `command_failed` هو الرمز الاحتياطي حين يفشل معالجك بلا رمز (`BridgeConfig.fallbackErrorCode` يثبّت عقدك القائم). نص الخطأ يُصدّى للموثوقين حصراً والرمز للجميع. |

الحمولات تصل مصفوفة نصوص أو نصاً واحداً أو أغلفة `{"data": [...]}` /
`{"payload": ...}` / `{"commands": [...]}` (`BridgeConfig.payloadWrapperKeys` — أضف مفتاح مجالك هناك إن استعملته بواباتك) — والحمولات
المضغوطة تمر كما هي: فك الضغط مسؤولية المضيف.

## الحدود (بقرار تصميمي)

- استماع IPv4 محلي حصراً (`127.0.0.1`)؛ لا ربط IPv6 في هذا الإصدار.
- تعشيش JSON مسقوف في مرور ما قبل الفك نفسه (`maxJsonDepth`، الافتراضي
  32) — الأعمق يُرد ب`413 payload_too_complex` قبل `jsonDecode`.
- من يمرر منافذ بديلة ل`start()` فصفحته تقرأ المنفذ الذي **يعيده**
  `start()` — لا تفترض المفضل أبداً (برنامج بنفس الجلسة قد يحتله).
- `BridgeConfig.extraHosts` يضيف سلطات مضيف يجيب عنها الخادم (الاسم
  المجرد يطابق `الاسم:المنفذ-المربوط` كالمدمجين). كل مدخل اسم تحت
  سيطرتك يحل إلى هذا الجهاز — الاسم غير المحلي هناك (عام كان أم
  شبكة خاصة) تنازلٌ صريح منك عن حارس إعادة ربط DNS لذلك الاسم
  وحده، والإقلاع يقوله مرة في السجل.
- السقوف والمهل تُتحقق عند بناء الخادم: قيمة غير موجبة في `BridgeConfig`
  أو في مهلة ممررة ترمي `ArgumentError` بدل رفض كل الطلبات بصمت.
- لا تفسير حمولات، لا هويات، لا ربط أجهزة، لا خزن — الجسر يحمل بايتات
  وأحكاماً لا غير.
- موجهات إذن الوصول للشبكة المحلية تختلف بين المتصفحات؛ تحصين طريقة
  الإرسال لا يعتمد عليها.
- سلوك السلك العدائي مثبت بشهود عقد (`wire_contract_test` يغطي 14 حالة
  رفض وعبور، و`priority_contract_test` يعيد 300 جولة طلبات ببذرة
  ثابتة) — والملفات العشوائية الأوسع على خارطة الطريق.
- لماذا لا TLS: شهادة ذاتية التوقيع على الحلقة الراجعة تدرّب
  المستخدمين على تجاوز التحذيرات ولا تشتري شيئاً أمام نموذج خصم
  المتصفح أعلاه؛ النقل حلقة راجعة حصراً لا يغادر الجهاز.

## الوثائق

- المثال الكامل القابل للتشغيل: `example/main.dart` (دارت صرفة، صفر تبعيات).
- الفحص الحي بالمتصفح: `dart run example/live_check.dart` ثم افتح
  العنوانين المطبوعين — توقع الأخضر كاملاً عبر `localhost` والحجوب المقصود
  عبر `127.0.0.1`. الأداة تخدم صفحة فحصها من الحلقة الراجعة وتأذن
  ل`localhost` وحده، فهي تثبت جولة CORS المحلية — وإثبات قبول أصل HTTPS
  عام يكون بفتح صفحتك المنشورة.
- وثائق الواجهة تسافر مع الحزمة على pub.dev.
